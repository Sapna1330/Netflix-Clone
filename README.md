### 🎬 Netflix Clone

A responsive Netflix-inspired web application designed to recreate the look and feel of a modern streaming platform. The project includes a clean user interface, movie and TV show sections, content cards, and responsive layouts for different screen sizes.

**Key Features:**

* Netflix-style homepage and user interface
* Movie and TV show content sections
* Responsive design for desktop and mobile devices
* Interactive navigation and content cards
* Clean and modern layout

**Technologies:** HTML | CSS | JavaScript
